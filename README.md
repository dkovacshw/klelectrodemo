# K-L Electro demo

Complete static website with the updated blue/white design, logo and animations.

1. Extract the ZIP and upload all files and folders directly to the repository root. Do not upload the ZIP itself or its containing folder.
2. In Settings > Pages, select Deploy from a branch, main, / (root), then Save.
3. Open the published URL shown by GitHub.

This is a demo: pages use noindex, and canonical URLs refer to klelectro.hu.
Do not set a custom domain for this preview. The production package is separate.
The custom 404 page assumes the repository is named klelectrodemo; if renamed,
replace /klelectrodemo/ in 404.html with the new repository path.
