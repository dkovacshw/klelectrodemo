## What changed for GitHub Pages

- Internal root links were prefixed with `/klelectrodemo/` so CSS, JavaScript and page links work under a GitHub Pages project URL.
- Footer credit was changed to `KD` linking to `https://github.com/dkovacshw`.
- Canonical and Open Graph URL tags now point to the GitHub Pages preview URL.

## Upload notes

Put the contents of this folder directly in the repository root, so `index.html` sits at the top level of the repo.

Then enable GitHub Pages from the repository settings, using the branch/folder that contains `index.html`.

## Later live-domain note

If this site later moves to `https://klelectro.hu/`, change the internal links back from `/klelectrodemo/...` to `/...`, and update canonical URLs/sitemap to the live domain.
